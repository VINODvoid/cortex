 # 🧠 CORTEX - Autonomous AI Agent Swarm for DeFi

  > Solana Mobile Hackathon Submission - AI-powered portfolio optimization

  ## 🎯 What is CORTEX?

  CORTEX deploys 10 specialized AI agents that coordinate autonomously to optimize your DeFi
  portfolio 24/7. Agents debate, vote, and execute on-chain while you sleep.

  ## 🤖 The 10 Agents

  - **YieldNeuron** - Maximizes DeFi returns
  - **RiskNeuron** - Protects against losses
  - **AirdropNeuron** - Farms token airdrops
  - **StrategistNeuron** - Coordinates all agents
  - **TaxNeuron** - Minimizes tax liability
  - **ComplianceNeuron** - Ensures legal boundaries
  - **SocialNeuron** - Builds reputation
  - **LearningNeuron** - Improves strategies
  - **GasNeuron** - Optimizes fees
  - **RebalanceNeuron** - Maintains allocation

  ## 🏗️ Tech Stack

  - **Mobile**: React Native + Expo
  - **Backend**: Bun + Hono
  - **AI**: Groq (Llama 3.3 70B)
  - **Blockchain**: Solana + Anchor
  - **DeFi**: Jupiter, Orca, Marinade
